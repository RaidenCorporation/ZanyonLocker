## New Drag-and-Drop:
The upcoming ZanyonLocker v4.0 update will introduce native drag-and-drop support directly into the core user interface, eliminating the need for tedious manual file browsing. Users will be able to simply grab any local file or folder from their desktop and drop it straight onto the application window to instantly stage it for AES-256 encryption. This streamlined pipeline will drastically reduce friction for non-technical users, transforming secure data locking into a dead-simple, one-step action.
