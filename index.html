  1. ❓ ZanyonLocker FAQ / Troubleshooting

Click on any question below to reveal the answer.

If your PC hasn't met the system requirements to officially run ZanyonLocker on your system, you might want to Upgrade your version of Windows, Get a newer & modern PC or Physically install a new RAM stick to your computer.

To find where your encrypted file has went, look for the place where the original decrypted file was (eg Desktop) and your encrypted .zanyon version should be there too.

If you lose your master key password for ZanyonLocker, there is absolutely no guarantee or way that you can get your file back. If you really need your file back and you lost your password to the file or forgot it, you can try looking if the master key file went into the Recycle Bin or if you hid it in File Explorer. Otherwise, there is no way to get your file back.
