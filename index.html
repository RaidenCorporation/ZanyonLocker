ZanyonLocker™ Overview

Welcome to the official homepage of ZanyonLocker™, a lightweight, secure file encryption tool for Windows.

ZanyonLocker™ allows you to easily protect your sensitive files with master key passwords and custom .zanyon encrypted file formats.

System Requirements

Requirement Minimum
Operating System Windows 10 22H2
Processor (CPU) Intel® Core™ i3
Memory (RAM) 4.00 GB RAM
Storage 2MB Free Space
Architecture x64 (64-bit)

Note: These are minimum requirements. If your computer meets or exceeds these specifications, ZanyonLocker™ will run properly. More available storage allows faster processing.

How To Check Your PC Info To See Whether ZanyonLocker™ Can Run On It

First, press Windows Key + R on your keyboard. Then, type msinfo32 and press enter. This will open your system information details.
